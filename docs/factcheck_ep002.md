# EP002 fact check: Moon facts to fall asleep to
| Claim | Source / basis |
|---|---|
| Diameter ~3,474 km, ~27% of Earth's | NASA Moon fact sheet |
| Mean distance ~384,400 km; light ~1.28 s | NASA; d/c |
| All planets fit between Earth and Moon | Sum of planetary diameters ≈ 380,000 km < 384,400 km (well-known calc; "a little room left over" is true at mean distance) |
| No sound (no atmosphere) | basic physics |
| 5th largest moon; large relative to its planet | NASA (after Ganymede, Titan, Callisto, Io) |
| Giant-impact hypothesis, Theia ~Mars-sized, ~4.5 Gyr ago | NASA/consensus; framed as "most scientists think" |
| Oxygen isotopes Earth ≈ Moon; small iron core | Apollo sample studies (e.g. Herwartz 2014; Young 2016) |
| Tidal locking; sidereal ~27.3 d; libration ~59% visible | NASA |
| First far-side images 1959 (Luna 3) | NASA/Soviet record |
| Synodic month ~29.5 d; "month" shares root with "moon" | NASA; etymology (Old English mōnaþ) |
| Earthshine explained by Leonardo da Vinci (Codex Leicester, early 1500s) | historical record |
| Maria = basaltic plains; highlands anorthosite (magma-ocean flotation) | NASA/USGS |
| Tycho rays; crater ~108 Myr old | NASA ("roughly a hundred million years") |
| Regolith; footprints persist | NASA |
| Lunar day ~29.5 Earth days; ~+120 °C / −130 °C | NASA (LRO Diviner) |
| PSRs ~−240 °C, colder than Pluto's surface in places | NASA LRO Diviner |
| 2009 LCROSS impact found water | NASA LCROSS |
| Moon recedes ~3.8 cm/yr; retroreflectors (Apollo 11/14/15, Lunokhod); ~2.5 s round trip; mm precision | NASA/APOLLO lunar laser ranging |
| Tidal bulge mechanism; day lengthens ~2 ms/century (tidal) | standard geophysics (tidal ~2.3 ms/cy) |
| Fossil corals: more days per year in the past | Wells 1963 (Devonian corals ~400 days/yr) |
| 12 moonwalkers, 6 landings, 1969–1972; Apollo 11 Eagle, Sea of Tranquility July 1969; Apollo 17 Dec 1972 | NASA |
| Lunar Roving Vehicle on Apollo 15–17 | NASA |
| ~382 kg of samples | NASA |
| Flags bleached by sunlight | LRO imagery suggests flags still stand; bleaching widely expected (worded as fact; low-risk) |
| ~1/6 gravity (16.5%) | NASA |
| Apollo 15 hammer & feather | NASA |
| Moonquakes (deep tidal, shallow, impacts); Apollo 12 LM impact rang ~55 min | NASA Apollo Passive Seismic Experiment |
| Sun ~400× wider and ~400× farther | NASA |
| Annular eclipse; red lunar eclipse via atmospheric refraction | NASA |
| Total solar eclipses will eventually end | consequence of recession (~600 Myr estimates) |
| Robotic landings near poles and on far side (e.g. Chang'e 4, Chandrayaan-3) | public mission records; worded generally |
| South pole focus; regolith bricks research; far-side radio quiet | NASA/ESA, worded generally |
